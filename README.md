# Amanda Stevens Portfolio

## Upload to GitHub Pages

1. Extract this ZIP file on your computer.
2. Create a public GitHub repository named YOUR-USERNAME.github.io for a site at https://YOUR-USERNAME.github.io.
3. Upload index.html, style.css, the other HTML pages, the assets folder, and .nojekyll to the repository root. Do not upload the ZIP itself or place these files inside an extra folder.
4. In Settings > Pages, select Deploy from a branch, then main and / (root), and click Save.
5. Wait for GitHub to publish the site; Settings > Pages will display its address.

You can also use an ordinary repository name, such as portfolio. The site will then be at https://YOUR-USERNAME.github.io/portfolio/. All local links in this export use relative paths to support either setup.

## Updating your site

Edit the HTML pages for content, style.css for layout, and assets for photos, figures, video, and PDFs. Commit the changes to GitHub to update the published website.

No installation or build step is required. Google Fonts are loaded from Google's stylesheet service when available; local system fonts are used as a fallback.
